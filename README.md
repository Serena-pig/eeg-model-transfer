# 2026-11-01：固定原始统计口径后的继续优化

## 口径固定

主指标始终为原60人、2400个10秒开发片段、不加权直接合并的ROC AUC。不对健康/抑郁组做1:1重加权，不重抽样，不改被试划分。等临床组权重AUC仅作辅助。原版官方88.13为用户反馈，和内部84.820069%不是同一批数据上的分数。

|完整方案|主指标AUC|
|---|---:|
|冻结原版|84.820069%|
|内层筛选新旧CNN混合后重训融合|84.799028%|
|冻结原版，仅拟合两个参数的残差修正|84.827014%|

后一方案仅增加0.006944个百分点，按被试配对重采样95%区间约为[-0.043333,+0.058825]个百分点，不能声称稳定提升，暂不替换88.13分版本。5个外折中4个局部AUC变化为正，逐一排除被试时59/60个总体差值为正；这些是复用开发集上的描述性稳定性检查，不是新独立测试，且未做累计搜索校正。

## 两条路径

第一条只用源3内折的CNN预测，比较gamma0.1/1、新旧CNN混合权重0/.25/.5/.75/1，以及常数或临床软门控；按源样本不加权合并AUC选择。保留原16病人子采样，完整重训80个融合头。门控在查询时不使用真实诊断；临床门控训练使用源诊断标签，源拟合时使用按被试交叉拟合概率。这里直接筛选基模型内层预测，不声称完成新的递归嵌套元模型验证。

第二条冻结全部原融合参数，使用新旧CNN的logit差异及其临床交互两个特征，仅拟合两个残差参数。修正乘以原模型的不确定度4p(1-p)，固定C=.01，用源训练数据上的BCE与全正负对排序损失学习；不拿训练预测冒充内层验证，不搜索残差超参数。外层被试从未用于拟合。原教师在源元训练数据上拟合过，残差拟合使用的源教师预测是训练预测，这不是独立验证成绩；最终报告只来自外层折外预测。

## 核验与限制

保存模型重新加载后残差预测最大误差约5.4e-13；概率保留6、8、10、12位小数时，主AUC均为84.827014%。原提交Excel SHA256不变。复核只重算新的融合/残差头，使用既有基础模型和CNN缓存预测，没有重新从MAT推理全部旧成员。
