## 新模型实际使用什么

每条10秒输入中，使用原预处理保存的5个2秒局部对数频带功率，6频带×30通道。同时保留该10秒的7频带通道相关图。不是估计每2秒的连接图变化，边来自整条10秒，随时间变化的是节点频带特征。

用相同源训练被试拟合的既有静态图作为冻结先验：3个checkpoint预测logit取均值，学习到的频带权重固定；源训练被试和查询被试互斥。将局部节点编码为12维，做一层原图/中心化图消息传递与通道注意力池化。随后比较两个新支路：时间均值、标准差、末段减首段的MLP摘要；或者12单元双向GRU及时间注意力。最终logit是0.5×截断至[-4,4]的静态先验加0.5×新支路logit；这个比例在查看本轮结果前固定，没有用外层调权。

只用源标签训练20轮，保存16/18/20轮状态平均预测。每个源病人一批8trial使用同一crop，神经训练抽样2健康+2抑郁；这只影响训练采样，主评估样本权重不变。不读取目标trial的其他50秒片段，也不读取公开测试信号训练。

## 内层选择与完整融合

每个外折的3内折分别训练摘要和GRU两支路，比较真实源内层预测的合并AUC。要求比静态图至少高0.001，否则回退静态图。5折选择为摘要、GRU、GRU、GRU、GRU。共30个新内层模型和5个新外层模型，未使用自身外层结果选择。

先保留旧87成员并追加所选时序图，共88成员，重训16病人子采样融合。结果未超过静态图后，再预先固定一个双图方案：分别保留静态图与时序图，共89成员，再重训16子采样融合。两种接法各80个融合头；没有外层权重网格搜索。元模型使用已有源内层预测训练，不声称做了新的递归嵌套元模型验证。

源内层单支路得分上涨，不等于完整融合一定上涨；这次两种接法都没有整体收益。尚不能据此断言时序信息没有价值，只能否定本轮实现带来更高整体AUC的说法。
