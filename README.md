## 视图与内层选择

在已有540维生理特征(6频带功率、局部2秒功率波动、对齐协方差对角)上，比较原中心化、同人8trial逐特征标准化、高斯秩归一化、加入相对频带功率、通道区域汇总及左右差值、每频带去空间均值六种表示。各配C=.03/.3/3，共18配置；全部只在源3内折选择，要求至少比原比较器高0.001，否则回退。

通道汇总使用项目既有CHANNELS顺序的分组，不声称已经官方核对真实导联或得出了生理因果结论。区域汇总与秩变换均未被最终选中。

5个外折选择为：被试内标准化、相对功率、相对功率、相对功率、被试内标准化，C均为0.3。只在源训练人群拟合StandardScaler；查询人的8trial中心化、方差和秩不使用标签，常数特征采用平均秩，不暗含trial排列。成对差分模型无截距，查询比较全部有序trial对，平均胜率作为排序分数。

完成270个源内层比较器拟合与5个选中外层拟合。第一种接法保留旧87成员、静态图、旧比较器和新视图，共90成员；第二种接法用新视图替换旧比较器，共89成员；均沿用16人群子采样、C=.01和原校准策略，各训练80个新融合头。没有根据外层扫描融合权重，也没有宣称做了新的递归嵌套元模型验证。
