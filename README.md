# 官方88.13反馈后的源数据增强试验

用户报告指定16次版本官方AUC评分为88.13。绑定Excel SHA256为dc0bd4751d35badc3731533edcb8f6374c8996d050e61c1c946d5eeeb642dec4，完整包commit42074b6a4224dddb292f4a371fc05716699f9103。反馈由用户提供，没有取得80条真实标签，也没有从总分倒推标签。

冻结原版模型和提交文件。新实验只读取60名开发被试，使用同一5外层/3内层划分，重放60份已有DE/raw神经分支检查点。固定4个输入视图：原序、时间反转、平移5秒、反转后平移5秒。原序对照与已保存概率最大差为0，所有查询不使用情绪或临床诊断标签。没有对查询更新神经网络参数。

三个神经分支的新概率只用源内层预测拟合各自尺度，重新拟合源训练范围内的标准化及每折16个排序融合头，其余83来源模型和协方差专家复用。C=.01、条件似然与成对排序损失各50%、被试抽样种子和80%抽样比例沿用原版，未做外层参数网格搜索。

主指标没有提高；按被试配对区间包含0。保留官方88.13版，未生成替换Excel或消耗提交机会。开发集反复使用，本结果不是独立确认，更不代表官方评分变化。当前未将官方测试信号或真实标签用于新训练；是否允许无标签测试域适配仍待组委会规则确认。

若官方已释放某批历史数据的真实标签并允许训练，可转作训练资料，但须以另一批未参与训练的数据评估。模型自己的预测只能作为可能出错的伪标签，不能称作已知答案。

本更新为研究代码及结果，不是新的完整比赛推理包。新模型引用现有来源检查点，原训练缓存和模型包均保留。
