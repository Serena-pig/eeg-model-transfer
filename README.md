## 信号处理与匹配对照

只读取2360个有效开发片段的原125Hz缓存，未使用公开测试信号或封存被试。源缓存来自既有1-45Hz预处理后下采样的10秒脑电。按7个频带(1-4/4-8/8-13/13-20/20-30/30-45/1-45Hz)对整条10秒做4阶Butterworth零相位滤波，然后切为5个2秒片段。各片段计算30通道协方差、固定10%迹对角收缩，再转为相关矩阵。匹配静态对照使用同一滤波后的整条10秒、同一收缩和精度。

缓存使用float16，实际量化误差上限记录在completion.json，小于0.00025。模型读入后转换float32。缓存不使用标签，只做每条信号内部处理；已检查其被试列表与封存集不相交。

## 网络与选择

两个新模型具有相同节点特征、结构、随机种子110161、训练批次与20轮优化配置：输入5段2秒×6频带×30通道局部功率，12维节点，一层连接图消息传递与通道注意力，再接双向GRU和时间注意力。唯一对照差异是连接边来自整条10秒并复制到5步，还是每步各自的2秒连接图。模型不使用trial编号或被试诊断作为预测输入。

每个外折在3个源内折上比较原静态图、匹配静态新模型及动态连接新模型的合并AUC；要求至少比原静态图高0.001，否则回退。最终5折分别选择：原静态、动态、动态、动态、原静态。前面的聊天进度曾误说前4折都选动态，已更正；此处与机器可读选择文件一致。

对3个选中动态连接的外折，保留原87个成员及既有静态图，再追加所选局部连接支路，重训16个病人子采样融合头；共48个新融合头。其余2折直接复用冻结静态图候选的完整融合工件，不把重复输入当新信息。元模型仅用源内层预测拟合，不声称完成了新的递归嵌套元模型验证。

## 计算与核验

参与方案的训练包含30个新内层网络及3个新外层网络。第二CPU进程提前完成第5折的独立内层任务，调用相同训练函数、参数和种子；为了和主进程保持整折间隔，另有1个完成但未发布的临时checkpoint，没有参与评分。训练数量审计与并行记录均保留。

5个最终网络(含2个回退的旧网络)从缓存EEG重新加载推理，预测差值0；最终融合输出差值小于5e-13。独立核验时查询情绪与诊断字段置为-1。未从MAT重新运行全部旧83成员。原提交Excel SHA256保持不变。

原版、84.8400候选、封存集与提交机会未改变。这仍是已反复使用开发人群的探索性结果，区间没有累计搜索校正；不能据此确认独立泛化提升。
