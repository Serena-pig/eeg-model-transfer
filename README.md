# 原版模型错误原因诊断：2026-10-31

本次分析使用冻结rank16方案在60名开发被试上的折外预测；每人只使用没有训练过该人的外折模型。实际提交则平均5个冻结外折模型，官方88.13为用户反馈。因此这里是训练方案的开发集诊断，不是80条公开测试预测的逐条错误分析，也不是新的官方评分。

## 发现与证据强度

|可能原因|本次证据|能得出的结论|
|---|---|---|
|信号质量|发现HC43近乎平直；排除该人后，幅值、异常尖峰比、裁剪点比例与错误的被试级关联区间均跨0|存在一个明确坏信号，但不能据此解释抑郁组整体较低；也不能排除当前质量指标未覆盖的伪迹|
|个体差异|抑郁组在同一人内的正负样本排序AUC也只有74.45%，健康组86.03%；源集背景特征距离与错误无稳定关联|仅校正不同人之间的分数尺度，不能修复同一个人内的排序错误；不能据此否定更复杂的个体差异|
|输入长度错配|extract_features.py将训练50秒trial切为5个10秒片段，公开测试每条也是2500点/250Hz=10秒|未发现训练50秒、推理10秒的直接输入长度错配|
|片段位置与时间稳定性|抑郁组第一10秒AUC68.91%，最后10秒81.52%；按20人配对重采样差值95%区间约+3.75至+21.58个百分点|有较强的探索性证据，当前模型对抑郁组的不同时间片段不够稳定；不能判断变化究竟来自情绪、刺激过程或非情绪因素|

同一50秒trial的5个片段中，预测跨过0.5的trial比例：抑郁组63.13%，健康组41.88%。跨阈值是预测不稳定指标，并非AUC错误的直接定义。

抑郁组5个位置的AUC依次为68.91%、79.16%、79.75%、71.08%、81.52%，不是严格随时间单调改善。因此不能简单认定“前段无情绪、后段有情绪”，也不能只挑后段当作新的比赛指标。

## 为什么还不能确认“没有捕捉到情绪”

数据标签描述积极/中性条件，没有逐秒真实情绪强度或人工伪迹标注。观察到的是模型在条件标签上的排序错误，无法直接分离情绪变化、脑电噪声和刺激/记录条件。

另外做了一个诊断性小模型：在同一人内，每次保留完整一个积极trial和一个中性trial，使用另6个trial标签训练线性模型，再平均4次预测。940多次小模型训练完成，但抑郁组平均被试AUC仅54.09%，弱于原方案74.45%。这不支持“给同一个人的少量标签就能简单解决”的设想，但受模型弱、trial少和不同任务设定限制，不能证明个体校准无用，更不能证明信号没有情绪信息。该探针无法用于没有标签的公开测试。

## 下一步应改什么

优先测试**同一训练trial的多个10秒片段之间的一致性训练或教师蒸馏**，让短片段学生学习同一长记录中更稳定的表征，同时保留每个10秒片段的监督分类目标，不强迫不同时间脑电特征完全相同。只在源训练被试构建跨片段监督，内层验证筛选，外层继续每条10秒独立评分。

这与之前的推理时翻转/平移增强不同：此前只平均同一片段的变换预测，新方向利用源数据中同一真实trial的不同片段训练学生。仍然可能失败，尚无新增AUC提升的证据。

将5段预测平均后的50秒诊断结果仅用于判断时间聚合是否减少噪声，**不是官方10秒AUC，不能拿来申报目标达成，也不能在公开测试中把不同trial随意平均**。

## 限制和保留内容

所有比较是已反复使用开发集的探索性分析；20名抑郁被试样本量有限，置信区间未做多重比较校正，相关性不代表因果。未读取封存集，未使用公开测试信号训练，未自动提交。原版提交Excel哈希未变。

audit.json包含全部被试级记录、质量关联、时间位置比较及诊断探针。per_person.csv可用Excel打开。paired_temporal_checks.json记录5000次按被试配对重采样结果。
