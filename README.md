## 方法与隔离

训练仍是原DE CNN的20轮、原随机种子、原监督损失、同样训练人群和优化器。增加同一个源被试、同一个50秒trial中两个不同10秒片段的预测logit一致性损失。两片段均来自源训练被试，目标标签沿用官方训练标签；目标不是伪标签。

3内折比较gamma=0/0.1/1，全部5外折在查看自身外层结果前都选中gamma=1。预测时仅用10秒特征与原方案的同人8trial上下文，不读取同一目标trial的其他50秒片段。原CNN关闭约束后的复现实验概率误差0；保存的5新CNN重新加载误差0，融合误差小于5e-13。新监督流的随机数状态保持匹配，第二片段使用独立随机流。

融合方案先固定，保留16人群子采样、C=0.01、原校准策略；不根据外层结果调整融合权重。替换方案87成员，追加方案88成员。使用既有源内层基模型预测训练融合，不声称新做了递归嵌套的元模型超参数搜索。

单支路表现改善不意味着融合必然改善；本次完整重训给出了直接的反例。DEP排序互补性有一些改善，但没有转化成完整融合的稳定增益。后续不能把77.46%当成完整模型结果，也不能把50秒平均的诊断AUC当成比赛结果。
