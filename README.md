固定原评估口径：60人、2400条10秒片段，全部预测不加权直接合并ROC AUC，不按临床组改成1:1。主输出预先固定subbag16_rawmean_calibrated。

|原版冻结模型|84.820069%|76.084375%|

原图候选比原版增加约0.019931个百分点，按被试配对重采样95%区间约[-0.049328,+0.087014]个百分点，包含0。源内层选图增加约0.015347个百分点，区间也包含0。因此尚无稳定的大幅提升证据，不晋升、不使用封存集、不提交。原版官方88.13分是用户反馈，不等于此表内部AUC，也不能推算新候选官方成绩。

## 临床专家：两条适配路线均未通过源内层筛选

在已训练的一致性CNN上，先比较只适配分类头、适配分类头及后部时间层，再测试整网适配30轮。抽样为3名源抑郁被试+1名源健康被试，回放健康样本；保留跨片段一致性与参数锚定。前两者12轮，整网30轮。分别完成30和15个源内层新模型训练。

选择条件提前固定：抑郁组源内层AUC至少提高0.005，且源内层总AUC不低于原支路0.005，再选抑郁组最好者；否则回退原一致性CNN。全部5折均回退。临床适配后的追加融合重训80个头，但结果与先前一致性CNN追加方案完全相同，没有新增信息，不重复当作提升。

## 新图网络

这不是继续微调原融合权重。网络输入7个频带的通道相关矩阵及8个频带的通道功率。两层消息传递结合原相关图与同人同crop8trial的中心化图，24维通道表示、注意力池化，输出8trial情绪分数。通道序号嵌入可学习；不假定脑区位置或生理因果关系。固定训练20轮、同一源随机种子，保存16/18/20轮状态并平均预测，训练目标为BCE、正负排序和4/8条件损失。

对齐版保持网络和训练配置，先对同一被试同一crop的8个协方差矩阵做欧氏对齐和矩阵对数；变换不使用标签、不使用其他50秒片段，不优化目标被试的模型参数。

每种图各训练原5外折/3内折的20个新网络，再在保留全部87个旧成员的前提下，追加该图支路并重训原16病人子采样融合；各80个融合头。健康/抑郁平衡抽样只用于神经网络训练，不改变主评估的原始合并权重。

## 源内层选图与验证边界

对每个外折，仅比较两个图在该外折源3内折的预测合并AUC，选择原图或对齐图，再使用对应已训练的外折融合工件。选择为原图/对齐图/原图/原图/原图；不按各外折测试AUC选择。不需要额外重训融合。元模型使用已有源内层基模型预测，未声称进行了新的递归嵌套元模型超参数验证。

原图、对齐图的保存网络均从缓存10秒EEG特征独立重新加载，预测最大差值0；融合输出差值小于5e-13。未从MAT重新运行全部旧基础成员。临床内层模型也检查过checkpoint重新加载与trial反序预测。原版Excel哈希保持不变。

全部结果仍来自反复使用的开发被试，且进行了多个探索性实验；没有多重搜索校正，不能把小幅上涨当作独立泛化确认。本分支是研究记录及新图模型/融合工件备份，依赖原项目、旧基模型与数据缓存，不是独立可提交比赛包。全部45个临床适配模型、40个图网络及240个融合头对应的工件已在工作区只读冻结并列入SHA256。
