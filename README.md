# EEG 当前最高已复核AUC模型：私有文件中转

## 下载和还原

1. 登录你自己的GitHub账号，在本页点击 **Code → Download ZIP**，下载整个仓库。也可以使用[整个仓库ZIP下载链接](https://github.com/Serena-pig/eeg-model-transfer/archive/refs/heads/main.zip)。
2. **完整解压**仓库ZIP，不要在压缩包内部直接运行脚本。
3. 双击根目录的 **00_merge_model.cmd**。它使用你电脑已有的Python3，自动合并320个分块，核验每块及完整ZIP的SHA256，再解压模型目录。无需逐个下载分块。
4. 打开生成的 **EEG_BEST_AUC_20261025** 文件夹，运行 **01_install_dependencies.cmd**。这一步会自动寻找已有Python3.12，安装CPU推理环境并自检；不用重新训练。
5. 将官方测试集10人的MAT或其原ZIP放到模型目录里的 **test_data**，运行 **02_generate_submission.cmd**。
6. 由你手动提交 **predictions** 中本次生成的80行Excel。CSV和审计附件不用提交；本仓库没有自动上传比赛的功能。

如果`py`命令不可用，可在此目录运行 `python merge_model.py`。合并脚本兼容你已有的Python3.13；模型推理环境使用Python3.12。
