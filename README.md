# 2026-10-31：伪标签可靠性与归一化DE核模型对照

本轮没有公开测试真实标签，也没有公开测试集训练或自动提交。

开发集置信度>=85%的849条中55条错误；HC组676条中37条错，DEP组173条中18条错。该统计来自已复用的开发集，不能直接推断公开80条的标签正确率。

新模型使用10秒DE时间均值与变异，按同一被试同一crop的8条记录进行中心化、zscore或高斯秩变换。3归一化×2核宽度×2正则=12配置；每个外折3内折共180次SVM拟合，5次源集最终重训。所有scaler只拟合本次训练子集，全部被试划分继承冻结协议；仅内层目标使用0.75组权重合并AUC+0.25DEP AUC。固定10%学生+90%冻结教师logit融合，不按外层调整权重。
