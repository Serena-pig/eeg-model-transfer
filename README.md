## 集合神经网络没有通过筛选

先测试同人8trial集合均值/标准差上下文及无位置编码的自注意力。输入来自匹配源训练被试拟合的冻结图网络72维嵌入，source-only均值标准差归一化。训练时随机打乱8trial顺序，保存模型后反序重算，防止记住正负标签排列。两种模型各15个内层训练，共30个20轮新模型；全部5折都未超过源内层增益门槛，回退旧静态图，未训练新外层神经网络。融合直接复用既有工件，结果不作为新增信息。

## 真正采用的是成对生理特征比较

使用6频带功率、局部2秒功率波动、无标签对齐协方差对角特征，共540维。对同一训练被试、同一crop中的积极与中性trial构造特征差，并加入反方向样本。比较线性模型和奇对称正弦随机特征近似非线性核，分类器无截距，保证交换两条输入时胜率互补。

查询时比较该人的每条记录与另外7条记录，平均预测胜率得到排序分数。不使用查询标签，不使用trial位置或真实诊断作为特征。各特征标准化仅拟合源训练人群，查询人的组内中心化/对齐属于固定无标签特征变换。

最初内层比较linear C=.03/.3及odd-RFF gamma=.25/1、C=.03/.3，共6配置。全部5折选择linear C=.3。随后仅因内层最优落在原范围边界，将线性范围扩为C=.3/3/30；这个扩展在查看首轮成对融合外层总分前固定。全部5折仍选择C=.3，因此扩展没有改变最终预测；对应融合工件直接复用，没有为相同配置重复重训。

选中比较器加入原87成员和既有静态图，形成89成员输入，仍按原16病人子采样、C=.01、固定原校准策略拟合融合，共80个新融合头。元模型使用源内层预测训练，未宣称做了新的递归嵌套元模型验证；未按外层调整融合权重。
