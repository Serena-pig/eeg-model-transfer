# 当前模型的固定4/4概率校正补丁（独立版本）

这不是重新训练模型。它在你已有的最高分模型输出80个概率之后，利用官方PDF明确给出的“每人4段中性、4段积极”信息，按70种可能分配计算概率后验；不读取测试标签、不改变模型权重、不硬性指定哪些段为积极，也不改变原始trial顺序。

在60名开发被试的跨被试OOF上，预先固定T=1对照：原始合并AUC82.320%→82.507%；按正常/抑郁各半加权80.232%→80.384%；更贴近官方10人80段的内部匹配估计80.029%→80.155%。这是小幅内部提升，尚未85%。单次预定8段子集和完整数据的结果均保留；没有挑选较高子集。整人重采样的加权增量95%区间约[+0.017,+0.273]个百分点，但没有校正长期多次开发，不保证官方测试提升。更复杂的自动校准主策略降分，其负结果也保留。

## 怎么使用

1. 先按原模型包流程安装依赖，并用02_generate_submission.cmd生成原始80行概率Excel。
2. 把本目录中的apply_fixed_count_calibration.py和03_fixed4_calibration.cmd复制到原模型目录（与02_generate_submission.cmd同一级）。
3. 双击03_fixed4_calibration.cmd。它会寻找predictions里最新的原始submission_best_*.xlsx，生成单独的`原文件名_fixed4_v2.xlsx`及审计JSON，原始Excel保留。
4. 也可把指定原始Excel拖到03脚本上，或手动执行`.venv\Scripts\python.exe apply_fixed_count_calibration.py "原始Excel路径"`。

**只应用一次。** 不要对已经校正过的结果再校正；脚本会拒绝带_fixed4_v2标记的输入。生成的Excel才是候选提交文件，脚本不会连接或代交比赛。与原始版本比较时请区分哪个文件被提交，不要同时上传两个版本来消耗机会。

以上内部结果对应固定的reference_bendr_fusion/person_bagged开发OOF。原包部署为五折平均，校正五折平均在未知官方测试上的效果没有独立成绩，不能把内部82.507%当成官方成绩。原模型本身包含无标签适配分支，其许可仍按赛规核对；本补丁仅改变概率，不训练任何参数。
